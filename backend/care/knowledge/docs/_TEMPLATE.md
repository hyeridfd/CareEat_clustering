## 3.2 저염식 제공 원칙

국·탕은 건더기 위주로 배식하고 국물은 반 컵 이하로 제공한다. 절임·젓갈류는 1일 1종 이내로 제한하고, 식탁에 소금·간장을 따로 두지 않는다.

조리 단계에서 간을 줄이는 대신 식초·레몬·깨·참기름 등으로 풍미를 보완한다.
